## Entry

> To: my manager
>
> i typed "i quit" eleven times this year and deleted it every time because the rent is due on the 1st and courage doesn't pay it

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (1–260 characters, per the competition gate) and prints it.
